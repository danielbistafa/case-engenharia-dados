Dashboard - Campeonato Brasileiro de Futebol

Este dashboard apresenta uma visao sintetica dos dados historicos do Brasileirao (2003-2025).

Os dados foram processados em uma arquitetura Data Lakehouse com as camadas Raw, Bronze, Silver e Gold usando PySpark e Delta Lake.
